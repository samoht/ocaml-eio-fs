# eio-fs

Filesystem helpers and an in-memory [Eio](https://github.com/ocaml-multicore/eio)
backend.

The library works with the standard `Eio.Path` interface. `Eio_fs.Fs.v ()`
creates a fresh filesystem in memory, `Eio_fs.Fs.load` populates it from an
existing directory tree, and `Eio_fs.Fs.tree` renders any `Eio.Path` tree.

## Installation

<!-- $MDX skip -->
```sh
opam install eio-fs
```

## Usage

```ocaml
Eio_main.run @@ fun _env ->
let fs = Eio_fs.Fs.v () in
Eio.Path.save ~create:(`Or_truncate 0o644) Eio.Path.(fs / "hello") "world";
assert (Eio.Path.load Eio.Path.(fs / "hello") = "world")
```

The in-memory provider is useful for tests and for scratch filesystems in
unikernels: application code receives an ordinary `Eio.Path` and does not need
to know which backend supplies it.

## Embedding a file tree at compile time

The `eio-fs-crunch` binary walks a directory tree and generates an OCaml
module (plus its interface) that embeds every directory, file and symbolic
link, in the style of [ocaml-crunch](https://github.com/mirage/ocaml-crunch).
A dune rule keeps the generated module in sync with the asset directory:

```
(rule
 (targets assets.ml assets.mli)
 (deps
  (source_tree static))
 (action
  (run %{bin:eio-fs-crunch} -o assets.ml static)))
```

The generated `assets.ml` carries the serialized tree, a value of type
`Eio_fs.Crunch.t` -- nobody writes entries by hand:

```
(* Generated by eio-fs-crunch. Do not edit. *)

let entries : Eio_fs.Crunch.t =
  Eio_fs.Crunch.
    [
      Dir { path = "/"; perm = 0o755 };
      File
        {
          path = "/index.html";
          perm = 0o644;
          contents = "<h1>Hello from the image</h1>\n";
        };
    ]

let load () = Eio_fs.Crunch.load entries
```

At runtime, `Assets.load ()` rebuilds the tree in the in-memory filesystem
and returns its root, so programs without a real filesystem -- unikernels,
tests -- get an ordinary `Eio.Path` view of their static assets. This
repository crunches [examples/readme/static](examples/readme/static) exactly
this way, and the
example below runs against the generated module:

```ocaml
Eio_main.run @@ fun _env ->
let fs = Assets.load () in
assert (
  Eio.Path.load Eio.Path.(fs / "index.html") = "<h1>Hello from the image</h1>\n")
```
